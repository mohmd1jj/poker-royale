
# Poker Royale MVP

## Stack
- Next.js frontend
- Node.js + Socket.IO backend
- WebRTC voice rooms
- PostgreSQL

## Features
- Texas Hold'em tables
- Real-time gameplay
- Voice chat
- Login/Register
- Admin panel scaffold

## Run

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
